# Koovera POS downloads

This repository holds the **Koovera POS installers**. Each version is a [GitHub Release](https://github.com/oosei25/smartmanagerpos-site/releases), and the download buttons on [koovera.com](https://koovera.com/) link straight to those Release files, for example:

```
https://github.com/oosei25/smartmanagerpos-site/releases/download/v0.2.2/Koovera-POS-Server-Setup-0.2.2.exe
```

To publish a new version, create a Release with the setup files attached, then update the download links on koovera.com.

**Do not rename, delete or archive this repository.** Release download URLs include the repository name; an archived repository can't take new Releases.

## The old website

The former SmartManager POS site (smartmanagerpos.com, retired November 2026) is gone. The GitHub Pages site for this repository now only redirects visitors to [koovera.com](https://koovera.com/). The Koovera website itself is not hosted here.
